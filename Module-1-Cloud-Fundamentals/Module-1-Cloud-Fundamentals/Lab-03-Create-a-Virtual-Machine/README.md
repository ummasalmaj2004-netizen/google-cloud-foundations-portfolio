# Lab 03: Create a Virtual Machine

## Lab Information

- Lab ID: GSP001
- Status: Completed

## Objective

Learn how to create and manage virtual machines using Google Compute Engine and deploy a web server.

## Services Used

- Google Compute Engine
- Virtual Machines (VMs)
- Cloud Shell
- NGINX Web Server

## Key Activities

- Created a virtual machine using Google Cloud Console
- Configured machine settings and storage
- Enabled HTTP traffic
- Connected to the VM using SSH
- Installed and configured NGINX
- Accessed the web server through the VM's external IP address

## Results

Successfully created a virtual machine, connected through SSH, installed NGINX, and hosted a web page.
