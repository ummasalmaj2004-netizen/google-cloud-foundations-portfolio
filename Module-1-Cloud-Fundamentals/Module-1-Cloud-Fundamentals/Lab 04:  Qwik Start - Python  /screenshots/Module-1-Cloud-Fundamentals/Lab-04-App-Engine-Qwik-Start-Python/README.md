# Lab 04: App Engine: Qwik Start - Python

## Lab Information

* Lab ID: GSP067
* Duration: 15 Minutes
* Difficulty: Introductory

## Objective

The objective of this lab was to learn how to deploy a Python web application using Google App Engine. The lab introduced serverless application hosting and demonstrated how applications can be deployed without managing servers or infrastructure.

## Services and Tools Used

* Google App Engine
* Python
* Cloud Shell
* Google Cloud Console
* Git Repository
