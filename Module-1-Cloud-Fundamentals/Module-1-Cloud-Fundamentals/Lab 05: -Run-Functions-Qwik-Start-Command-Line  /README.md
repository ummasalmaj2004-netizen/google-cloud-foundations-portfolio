# Lab 05: Cloud Run Functions: Qwik Start - Command Line

## Lab Information

* Lab ID: GSP080
* Duration: 15 Minutes
* Difficulty: Introductory

## Objective

The objective of this lab was to learn how to create, deploy, and test a Cloud Run function using the Google Cloud command line. The lab introduced event-driven serverless computing and demonstrated how functions can automatically respond to requests and events.

## Services and Tools Used

* Cloud Run Functions
* Cloud Shell
* gcloud CLI
* Google Cloud Console
* Cloud Logging

## Key Steps Performed

1. Opened Google Cloud Console and activated Cloud Shell.
2. Configured the project environment.
3. Created a Cloud Run function.
4. Wrote and deployed function code using the command line.
5. Tested the deployed function using an HTTP request.
6. Verified successful execution of the function.
7. Examined logs generated by the function.
8. Monitored function activity through Cloud Logging.

## Results

Successfully created, deployed, and tested a Cloud Run function using Cloud Shell. Verified function execution and reviewed logs to confirm proper operation.

This lab introduced serverless computing using Cloud Run Functions.
