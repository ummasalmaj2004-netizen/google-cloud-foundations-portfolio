# Lab 06: Google Kubernetes Engine (GKE) Qwik Start

## Lab Information

* Lab ID: GSP100
* Duration: 25 Minutes
* Difficulty: Introductory

## Objective

The objective of this lab was to learn how to deploy and manage containerized applications using Google Kubernetes Engine (GKE). The lab introduced Kubernetes clusters, application deployment, and service management in a cloud environment.

## Services and Tools Used

* Google Kubernetes Engine (GKE)
* Kubernetes
* Cloud Shell
* kubectl
* Google Cloud Console
* Compute Engine

## Key Steps Performed

1. Opened Google Cloud Console and activated Cloud Shell.
2. Created a Google Kubernetes Engine cluster.
3. Connected to the cluster using kubectl.
4. Deployed a containerized application to the cluster.
5. Created a Kubernetes service to expose the application.
6. Verified application accessibility through the service endpoint.
7. Observed cluster resources and workloads.
8. Deleted the cluster after completing the lab.

## Results

Successfully created a GKE cluster, deployed a containerized application, exposed it through a Kubernetes service, and managed cluster resources using Kubernetes commands.
