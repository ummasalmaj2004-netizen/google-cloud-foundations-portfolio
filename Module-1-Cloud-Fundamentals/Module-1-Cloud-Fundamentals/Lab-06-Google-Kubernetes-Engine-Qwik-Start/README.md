# Lab 06: Google Kubernetes Engine (GKE) - Qwik Start

## Lab Information

- Lab ID: GSP100
- Duration: 25 Minutes
- Difficulty: Introductory
- Status: Completed

## Objective

Learn how to create a Google Kubernetes Engine (GKE) cluster, deploy a containerized application, expose it through a service, and manage Kubernetes resources.

## Services Used

- Google Kubernetes Engine (GKE)
- Kubernetes
- Cloud Shell
- Compute Engine

## Key Activities

- Created a GKE cluster
- Connected to the cluster using kubectl
- Deployed a containerized application
- Created a Kubernetes service
- Accessed the deployed application
- Deleted the cluster after testing

## Results

Successfully deployed and managed a containerized application using Google Kubernetes Engine.
