# Google Cloud Computing Foundations Portfolio

## Overview

This repository contains my work for the Google Cloud Computing Foundations assessment. The project documents my completion of hands-on Google Cloud labs and demonstrates practical experience with cloud computing concepts, infrastructure management, networking, security, data processing, and artificial intelligence services.

The repository is organized into four modules, with each lab containing a dedicated README file, screenshots, and evidence of completion. A GitHub Wiki is also included to document progress, reflections, challenges, and key learning outcomes.
