# Lab 07: Speech-to-Text API: Qwik Start

## Lab Overview

This lab demonstrated how to use Google Cloud Speech-to-Text API to convert audio recordings into text transcriptions.

## Objectives

* Create an API key
* Configure Speech-to-Text requests
* Submit audio for transcription
* Review transcription results

## Services Used

* Speech-to-Text API
* Cloud Shell

## Key Tasks Performed

1. Enabled the Speech-to-Text API.
2. Generated an API key.
3. Prepared a transcription request.
4. Submitted audio data to the API.
5. Retrieved transcription results.
6. Verified recognized speech output.
