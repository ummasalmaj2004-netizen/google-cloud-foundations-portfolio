# Module 4: Data, ML & AI

## Overview

This module focuses on Google Cloud services for data processing, analytics, machine learning, and artificial intelligence. Through these hands-on labs, I explored cloud-based data pipelines, big data processing, natural language processing, speech recognition, and video analysis services.

## Learning Objectives

* Understand large-scale data processing in Google Cloud.
* Work with Apache Spark and Dataflow pipelines.
* Explore machine learning and AI services.
* Process structured and unstructured data.
* Analyze text, speech, and video using Google Cloud APIs.

## Labs Completed

### Lab 01: Managed Service for Apache Spark

* Created and managed Apache Spark clusters.
* Executed Spark jobs.
* Modified cluster worker configurations.

### Lab 02: Managed Service for Apache Spark: Qwik Start - Command Line

* Managed Spark clusters using Cloud Shell.
* Submitted Spark jobs through the command line.
* Scaled cluster resources.

### Lab 03: Dataflow: Qwik Start - Templates

* Created Dataflow pipelines using templates.
* Connected Pub/Sub with BigQuery.
* Processed streaming data.

### Lab 04: Dataflow: Qwik Start - Python

* Installed Apache Beam SDK.

### Lab 05: Alteryx Designer Cloud: Qwik Start

* Explored cloud-based analytics workflows.
* Created and executed data preparation processes.

### Lab 06: Cloud Natural Language API: Qwik Start

* Analyzed text using Natural Language API.
* Performed sentiment analysis.

### Lab 07: Speech-to-Text API: Qwik Start

* Converted audio to text.

* Examined transcription results.

### Lab 08: Video Intelligence API: Qwik Start

* Analyzed video content.
* Detected labels and objects.
