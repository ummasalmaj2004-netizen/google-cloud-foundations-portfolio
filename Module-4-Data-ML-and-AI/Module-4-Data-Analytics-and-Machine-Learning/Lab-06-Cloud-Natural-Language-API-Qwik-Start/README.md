## Objective

This lab introduces Google Cloud Natural Language API and demonstrates how machine learning can analyze and understand human language.

## Learning Outcomes

In this lab, I learned how to:

- Create and use an API key
- Enable the Cloud Natural Language API
- Submit text for analysis
- Extract entities from text
- Interpret Natural Language API responses
