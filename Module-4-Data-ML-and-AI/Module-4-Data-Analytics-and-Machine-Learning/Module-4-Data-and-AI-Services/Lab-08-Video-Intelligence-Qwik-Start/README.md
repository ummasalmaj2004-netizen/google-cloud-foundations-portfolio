# Lab 08: Video Intelligence: Qwik Start

## Lab Overview

This lab introduced the Video Intelligence API and demonstrated how to analyze video content using machine learning.

## Objectives

* Create a service account
* Configure API access
* Submit video analysis requests
* Review video annotation results

## Services Used

* Video Intelligence API
* IAM
* Cloud Shell

## Key Tasks Performed

1. Enabled the Video Intelligence API.
2. Created and configured a service account.
3. Generated authentication credentials.
4. Submitted an annotate video request.
5. Processed video metadata.
6. Reviewed object and scene annotations.
