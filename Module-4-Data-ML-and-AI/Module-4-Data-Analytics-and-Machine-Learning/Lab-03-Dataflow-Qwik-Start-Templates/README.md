## Objective

This lab introduces Dataflow templates and demonstrates how to build a streaming data pipeline.

You will learn how to:

- Create a BigQuery dataset and table
- Create a Cloud Storage bucket
- Use a Dataflow template
- Stream data from Pub/Sub to BigQuery

## Services Used

- Dataflow
- Pub/Sub
- BigQuery
- Cloud Storage
