## Objective

This lab demonstrates how to manage Apache Spark clusters using the Google Cloud command line.

You will learn how to:

- Create a Spark cluster using gcloud commands
- Submit a Spark job from Cloud Shell
- Monitor job execution
- Scale cluster workers from the command line

## Services Used

- Managed Service for Apache Spark
- Cloud Shell
- gcloud CLI
