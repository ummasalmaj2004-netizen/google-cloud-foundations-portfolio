## Objective

This lab introduces Alteryx Designer Cloud (formerly Trifacta), a cloud-based data preparation platform used for cleaning and transforming datasets before analysis.

## Learning Outcomes

In this lab, I learned how to:

- Import datasets into Alteryx Designer Cloud
- Identify and correct mismatched data values
- Apply data transformations
- Join multiple datasets together
- Prepare data for analytics workflows

## Services Used

- Alteryx Designer Cloud
- Google Cloud Storage
- Cloud Shell
