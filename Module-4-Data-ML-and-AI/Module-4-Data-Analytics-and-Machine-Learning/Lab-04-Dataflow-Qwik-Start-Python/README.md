## Objective

This lab introduces Apache Beam and Dataflow using Python.

You will learn how to:

- Create a Cloud Storage bucket
- Install the Apache Beam SDK for Python
- Build and run a Dataflow pipeline
- Execute a pipeline remotely on Google Cloud

## Services Used

- Dataflow
- Apache Beam SDK
- Cloud Storage
- Cloud Shell
